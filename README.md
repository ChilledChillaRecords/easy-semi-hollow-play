# Easy Semi Hollow – play it in your browser

The browser version of **Easy Semi Hollow**, the physically modelled semi-hollow jazz guitar by
[Chilled Chilla Records](https://chilledchillarecords.com/easy-semi-hollow). It is embedded on
chilledchillarecords.com/easy-semi-hollow and served from here with GitHub Pages.

Play with your computer keyboard (A–L white keys, W E T Y/Z U O P black keys, Space = sustain,
← → octave), the mouse or a MIDI keyboard (Web MIDI in Chrome and Edge).

The plug-in for your DAW (VST3, Audio Unit, standalone; Windows and macOS) is available at
[chilledchillarecords.com/easy-semi-hollow](https://chilledchillarecords.com/easy-semi-hollow) with a free 7-day trial.

The user manual (PDF, English) is here too: [Easy-Semi-Hollow-Manual.pdf](Easy-Semi-Hollow-Manual.pdf).
